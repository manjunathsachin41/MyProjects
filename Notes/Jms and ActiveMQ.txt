JMS-Java Messaging Service
JMS is a Java API specification that defines a standard way for Java applications to create, send, receive, and read messages.
JMS is an API, not an implementation
Messaging Paradigms: 
JMS supports two primary messaging paradigms:
Point-to-Point (Queues): Messages are sent to a specific queue and consumed by only one consumer.
Publish/Subscribe (Topics): Messages are published to a topic and can be received by multiple subscribers.


ActiveMQ:
JMS Provider/Message Broker: Apache ActiveMQ is an open-source message broker that implements the JMS specification. 
It provides the actual software infrastructure for facilitating message-oriented communication.
